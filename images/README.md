## نصائح للصور

- مربعة (مثلاً 800×800) عشان تطلع مضبوطة في القائمة.
- خفّف حجم كل صورة تحت 200 كيلوبايت عشان المنيو يفتح بسرعة.
- الصيغ المدعومة: `jpg` / `png` / `webp`.
- لو الصورة ناقصة، يظهر مكانها مربع فاضي بدون ما يتعطل المنيو.
